# SOFT DESIGN Website

A lightweight, responsive website for SOFT DESIGN, an independent software engineering business focused on C# and Microsoft .NET development.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Static hosting with GitHub Pages

The site has no build step or package dependencies.

## Project Structure

| Path | Purpose |
|---|---|
| `index.html` | Page content, SEO metadata, and structured data |
| `css/style.css` | Design system, layout, and responsive styles |
| `js/main.js` | Mobile navigation and current-year display |
| `assets/` | SOFT DESIGN logo files in SVG and JPEG formats |
| `CNAME` | Custom domain configuration |
| `robots.txt` | Crawler access rules and sitemap location |
| `sitemap.xml` | Public page URLs for search engine discovery |

## Logo Assets

Use the horizontal logo on the website and other wide layouts. The stacked logo and symbol are available for compact placements. SVG files are preferred for web use because they scale cleanly; JPEG copies are provided for contexts that require raster images.

The light horizontal logo is intended for dark backgrounds. Other logo files use colors suited to light backgrounds.

## Contact

The site does not include a message form. GitHub Pages does not process form submissions, so visitors are directed to LinkedIn to contact Fidan.

## Local Preview

Open `index.html` in a browser. No build or installation steps are required.

## Hosting and Domain

The site is designed for GitHub Pages. Keep `CNAME`, the canonical URL, Open Graph URL, and sitemap URL aligned if the public domain changes.
