# SOFT DESIGN website

A static, single-page website for SOFT DESIGN, an independent software engineering business. The site uses HTML, CSS, and vanilla JavaScript and is intended for GitHub Pages.

## Files

- `index.html` contains the page content, SEO metadata, and structured data.
- `css/style.css` contains the visual system and responsive layouts.
- `js/main.js` provides the mobile navigation and current year.
- `CNAME` configures the existing custom domain.
- `robots.txt` and `sitemap.xml` provide basic search engine discovery files.

## Contact

The website does not include a message form because static GitHub Pages hosting cannot process submissions. Visitors can contact Fidan through the linked LinkedIn profile. No third-party form service or tracking script is configured.

## Local preview

Open `index.html` in a browser. No build step or package installation is required.

Keep the canonical URL, Open Graph URL, sitemap URL, and `CNAME` aligned if the public domain changes.
