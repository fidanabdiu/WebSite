ASSESS · IMPROVE · MAINTAIN

Make change manageable and grounded in context.

Legacy software often contains years of accumulated business decisions. A useful modernization effort recognizes that context, identifies the parts that limit change and chooses a practical sequence of improvements.

Work can include

  • Reviewing existing .NET applications
  • Refactoring application structure
  • Modernizing ASP.NET MVC and Web Forms systems
  • Improving maintainability and testability
  • Extending useful applications
  • Planning incremental technical change

Incremental by default

Recommendations depend on the system and its constraints. Some applications benefit from targeted changes; others need a broader migration plan. The first step is understanding what is in place and what the business needs next.

Selected experience includes an ASP.NET MVC replacement for an existing Web Forms application and ongoing work across web, desktop and enterprise systems.
